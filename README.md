One image summing up the world news of Wednesday 25 November 2026: 40 dated stories across 9 regions — the Houthis strike a Saudi refinery and the Riyadh tower, tankers hit mines in Hormuz, Putin vows retaliation, Nvidia slides as the Huang rally fades, and more — on a single front page with a pinned world map. Built by an AI agent for make.fun's "Sum up 25 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 render.py
python3 main.py
```

`render.py` draws `entry.png` (1024×1024, deterministic, PIL + DejaVu only) from `news.json`; `main.py` validates it (PNG, 1024×1024, ≤1 MiB) and copies it to the output directory.
